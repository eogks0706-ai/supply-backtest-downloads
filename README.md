## 일봉 계산기

자동 가상매매에서 시작일·종료일을 선택하고 **선택 기간 샘플 → 시작 / 계속**을 누르면 연습할 수 있습니다. 샘플은 현재 날짜를 기준으로 만드는 합성 자료로 실제 투자 성과가 아닙니다.

실제 자료는 **CSV 폴더 선택 → 선택 기간 준비**를 사용합니다. data.csv·calendar.csv와 시작일 전 60거래일 이력이 필요합니다. 실제 자료의 날짜를 바꾸지 않습니다.

## 토스 연결

실시간 가상매매의 **토스 연결 안내**에서 공식 API 페이지를 열고 토스에서 직접 로그인·API 키 발급·허용 IP 등록을 완료하세요. 앱에서 키 입력 → 연결 확인 → 매매 시작 순서로 진행합니다. 최초 인증을 대신하거나 실계좌 주문을 전송하지 않습니다. **실제 토스 인증·장중 호가 수신은 아직 미검증**입니다.

## 계산기 방식

수동·일봉·실시간 가상매매는 기본적으로 자동 저장하지 않습니다. **삭제·초기화**로 현재 결과를 버리고 다시 시작할 수 있습니다. 필요한 결과는 저장/내보내기 버튼으로 직접 보관하세요. 앱 종료 시 미저장 결과는 사라집니다. 과거 버전의 파일과 별도 저장 파일은 자동 삭제하지 않습니다.

진행률·처리 날짜·완료 원인을 표시합니다. 토스 실시간은 연결/감시/장외 대기/사용자 중지/오류 종료 상태를 구분합니다.

코드 서명 없는 Windows x64 테스트 버전입니다. 실제 KRX 수집·토스 접속·다른 PC·화면 배치는 미검증입니다. 손익절 −10%/+5%는 판단 기준이며 정확한 가격 체결을 보장하지 않습니다. 자세한 조건은 배포 페이지의 INSTALL.md를 확인하세요.
