## 자산 대시보드와 일봉 계산기

가상 시작 자금을 입력하고 기간을 선택한 뒤 **선택 기간 샘플 → 시작 / 계속**을 누르세요. 10종목 분산을 확인할 수 있는 합성 샘플이며 실제 투자 성과는 아닙니다. 실제 CSV는 원래 날짜를 유지한 채 선택한 기간만 계산합니다.

시작 자금·현재 평가자산·손익·현금·보유 평가액과 자산 변화 그래프를 표시합니다. 실제 토스 계좌 잔고가 아닙니다. 실제 자료의 후보가 10개 미만이거나 매수 자금이 부족하면 남은 비중을 현금으로 유지합니다.

## 미래 기간 실시간 가상매매

토스 공식 API 키와 허용 IP 설정 후 앱에서 연결하세요. 미래 종료일까지 실제로 수신되는 호가로 계산합니다. 처음 선정한 목록을 유지하며 거래일마다 같은 목록으로 재투자합니다. 앱/PC가 켜져 있고 연결된 동안만 작동하며 종료일 15:20(KST)에 완료합니다. 미청산 보유분은 평가 상태로 남습니다. 실제 주문은 전송하지 않습니다.

## 보안 및 검증

v1.4.0은 인증 리다이렉트 차단, 인증 정보 삭제 및 늦은 인증 응답 제외 기능을 포함합니다. 기능·보안 오프라인 테스트와 설치 검증을 수행했습니다. **실제 토스 인증·장중 수신은 아직 미검증**이며 코드 서명 없는 테스트 버전입니다. 계정 최초 인증을 앱이 대신할 수는 없습니다. 세부 제한과 보안 리뷰는 배포 페이지를 확인하세요.
